# Spec: Project structure

The toolchain, repo layout, and app stack every feature builds on. Conventions are recorded in [ADR 0001](../../architecture/0001-toolchain-conventions.md).

## Toolchain

Vite+ (template-generated by the user), pnpm, mise with the vite-plus plugin. Scaffolding the template is user-owned work; everything below assumes it exists.

## Repo layout

Vite+ project at the repo root, keeping `docs/` as-is:

```
/
├── data/                      ← checked-in snapshots (JSON), the app's only inputs
│   ├── deepswe-v1.1.json
│   ├── openrouter-throughput.json
│   ├── tiers.json
│   └── model-mapping.json
├── scripts/                   ← TS refresh scripts, run via the toolchain
│   ├── refresh-deepswe.ts
│   └── refresh-openrouter.ts
├── src/                       ← React app
│   ├── data/types.ts          ← shared data-shape types (scripts import from here)
│   ├── data/derive.ts         ← row expansion + maths (pure functions)
│   └── ...
└── .github/workflows/ci.yml
```

Data is imported at build time (`import data from "../data/..."`), no runtime fetch. Scripts and app share the types in `src/data/types.ts`.

## App stack

React + TypeScript + TanStack Table on the Vite+ toolchain, with shadcn/ui components (Base UI primitives) and Tailwind for styling ([ADR 0001](../../architecture/0001-toolchain-conventions.md)).
